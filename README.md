## 📊 ¿Qué mido exactamente?

- **Precisión factual** → ¿El agente dice cosas correctas?
- **Consistencia** → ¿Responde igual a preguntas similares?
- **Adecuación por edad** → ¿Usa lenguaje apropiado para niños, adolescentes o adultos?
- **Sesgos no deseados** → ¿Tiene respuestas problemáticas?
- **Confiabilidad test-retest** → ¿Es estable en el tiempo?
